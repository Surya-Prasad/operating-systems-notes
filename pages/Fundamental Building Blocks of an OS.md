- Cycles of an Instruction
	- We have a pipeline, say i1, i2, i3...
	- Usual hardware has 5 stages
		- `FETCH` - Gets the instruction from Program Counter
		- `DECODE` - Fetching values from registers and decode instruction
		- `EXECUTE` - Executes logic
		- `MEMORY` - Any memory altering operation
		- `WRITEBACK` - Writing to Registers
	- They have dependencies, you might have to stall, etc between instructions
	- When encountering `PAGEFAULT`
		- If no `PAGEFAULT` happens, then $instruction_{n+1}$ is invoked
		- `PAGEFAULT` can happen either memory or fetch
		- When encountered, the PC refers to the Instruction Vector Table (Or ISR Table) and resolves/handles the instruction and then PC would point to current instruction again

- Interrupt
	- Hardware/Software signal sent to CPU to temporarily freezes the current program
	- Types of Interrupts
		- Hardware/External
			- Generated by Physical devices outside CPU
			- Completely asynchronous (Does not wait for confirmation or sync to perform an action)
		- Software/System Calls
			- Intentionally triggered by running program
			- Requests to poll OS for running services
